Handy — macOS 화면 공유 지원 수정본
=================================

이 파일은 Handy의 비공식 수정본입니다.
원본 프로젝트: https://github.com/cjpais/Handy
라이선스: MIT (동봉한 LICENSE.txt 참고)

화면 공유의 공유 클립보드 설정
--------------------------
로컬 Mac의 '화면 공유' 앱에서:
  Edit → Use Shared Clipboard = ON 유지 가능 (새 붙여넣기 경로)
한국어 메뉴: 편집 → 공유 클립보드 사용
ON에서는 화면 공유의 기본 Paste(붙여넣기) 동작을 직접 실행합니다.
붙여넣는 중에도 OFF로 전환하지 않으며, Send Clipboard가 회색이어도 됩니다.
OFF를 선택한 경우에는 기존 Send Clipboard 후 붙여넣기 경로를 유지합니다.
새 ON 경로는 단위 테스트를 통과했지만 실제 Mac 간 연결 검증은 아직 필요합니다.
아래의 서로 다른 두 문장 입력과 일반 복사·붙여넣기를 모두 확인하세요.

지원 대상
---------
파일 이름이 universal인 설치본은 Apple Silicon(M1 이상) 및 Intel Mac용입니다.
파일 이름이 arm64인 설치본은 Apple Silicon 전용이며 Intel Mac에서 실행할 수 없습니다.
최소 실행 대상으로 macOS 11.0 이상을 지정했습니다.
모든 macOS 버전 및 Intel 실기기에서의 동작을 검증한 것은 아닙니다.
이번 화면 공유 수정은 macOS 기본 '화면 공유' 앱에서 다른 Mac에 접속하는
경우를 대상으로 합니다. 다른 VNC 클라이언트/원격 운영체제는 미검증입니다.

설치
----
1. 기존 Handy가 실행 중이면 메뉴 막대의 Handy 메뉴에서 완전히 종료합니다.
2. DMG를 열고 Handy.app을 Applications 폴더로 드래그합니다.
   기존 Handy.app이 있으면 교체됩니다. 필요하면 기존 앱을 먼저 보관하세요.
3. DMG를 추출한 뒤 응용 프로그램 폴더의 Handy를 실행합니다.

최초 실행 시 보안 경고
---------------------
기본 배포본은 빌드 기계에 보관한 동일한 로컬 인증서로 서명합니다.
Apple Developer ID 서명 및 공증을 받은 앱은 아닙니다.
인터넷에서 받은 파일은 macOS가 실행을 차단할 수 있습니다.
출처를 신뢰하는 파일일 때만 다음 절차를 진행하세요.

앱 실행을 한 번 시도한 뒤:
  시스템 설정 → 개인정보 보호 및 보안 → 보안 → '확인 없이 열기'
를 선택하고 확인 창에서 실행을 승인합니다. 구버전 macOS에서는
'시스템 환경설정 → 보안 및 개인 정보 보호 → 일반'에 해당 항목이 있습니다.
보안 기능 전체를 끄거나 알 수 없는 터미널 명령을 실행할 필요는 없습니다.
Apple 공식 안내: https://support.apple.com/ko-kr/102445

권한 및 최초 설정
-----------------
마이크와 손쉬운 사용(Accessibility) 권한을 Handy에 허용합니다.
이미 유효한 권한이 있으면 설정 화면을 건너뛰고 기존 승인을 사용합니다.
현재 앱의 승인이 없으면 macOS의 공식 승인 창을 한 번 요청합니다.
설정 화면을 동시에 두 번 열지 않으며 + 버튼 유무에 의존하지 않습니다.
승인 창을 닫은 뒤 '시스템 설정 열기'를 누르면 설정 화면만 엽니다.
이전 임시 서명에 묶인 승인과 현재 실행 파일의 승인은 다를 수 있습니다.
현재 승인 상태를 다시 읽으려면 '권한 다시 확인', 프로세스를 새로 시작하려면
'Handy 다시 시작'을 사용합니다. 같은 인증서로 만든 후속 빌드는 동일한 앱
식별 조건을 유지합니다.

0.9.11의 'Handy 권한 복구'는 현재 승인이 거부된 경우에만 macOS 공식 도구로
Handy의 기기 제어 승인 한 건을 초기화한 뒤 정상 재시작합니다.
유효한 기존 승인은 그대로 보존하고, 마이크 등 다른 권한은 초기화하지 않습니다.
macOS의 새 승인 자체는 사용자가 결정합니다.

다른 빌드가 실행 중이면 새 빌드가 이전 Handy를 정상 종료한 뒤 시작합니다.
같은 빌드를 다시 열면 설정 창을 표시합니다. 녹음 제어용 명령이나
독립 파일 전사 작업으로는 실행 중인 GUI 앱을 교체하지 않습니다.

앱 검색에 Handy가 여러 개 나타날 때
---------------------------------
응용 프로그램의 /Applications/Handy.app 하나를 실행하세요. 설치 후에는
DMG를 추출합니다. 설치된 Handy는 새 배포본의 Handy 설치 디스크를 자동으로
추출합니다(다른 디스크 및 사용 중인 디스크는 강제 추출하지 않습니다).
패키징 완료 후 빌드용 .app 사본과 임시 사본을 정리하고 DMG만 배포합니다.
업데이트 전에 내려받은 앱 사본이 다른 폴더에 있다면 그 사본도 검색될 수 있습니다.

음성 인식 모델은 앱에서 선택하여 별도로 다운로드합니다(인터넷 필요).
이 설치 파일에는 배포자의 녹음, 전사 기록, 계정/API 키, 개인 설정 및
다운로드한 음성 인식 모델이 포함되어 있지 않습니다.

설정 창은 메뉴 막대의 Handy 아이콘 → Settings에서 열 수 있습니다.
Handy가 이미 실행 중이면 응용 프로그램 폴더에서 다시 열어도 됩니다.

정상 종료
---------
Handy 설정 창 아래쪽의 '종료' 버튼을 누르세요. 권한 설정 화면에도 있습니다.
또는 로컬 Handy 창을 맨 앞으로 가져온 뒤 Cmd+Q를 누르세요.
메뉴 막대 아이콘이 보이면 Handy 아이콘 → 종료로도 종료할 수 있습니다.
메뉴 막대는 Mac 화면 맨 위의 Apple 로고와 시계가 있는 가로줄입니다.
설정 창의 닫기 버튼은 창만 숨기므로 정상 종료에는 위 방법을 사용하세요.

macOS 화면 공유에서 사용
-----------------------
1. Handy는 말을 입력하는 로컬 Mac에서 실행합니다.
2. macOS '화면 공유' 앱으로 원격 Mac에 제어 모드(Control Mode)로 접속합니다.
3. 일반 복사·붙여넣기를 유지하려면 '편집 → 공유 클립보드 사용'을 켜 두고,
   로컬 클립보드에 텍스트가 있을 때 '편집 → 붙여넣기'가 활성화되는지 확인합니다.
   ON에서는 Handy가 기본 Paste 동작을 실행하며, 설정을 바꾸지 않습니다.
4. Handy의 붙여넣기 방식을 일반 클립보드 붙여넣기(Cmd+V)로 설정합니다.
5. 원격 Mac의 입력칸을 클릭하고 Handy 단축키로 음성을 입력합니다.
6. 전사가 끝나고 붙여넣기가 완료될 때까지 창이나 연결을 바꾸지 마세요.
7. 화면 공유 창에 계속 머무른 상태에서 서로 다른 두 문장을 차례로
   입력하여 두 번째 문장이 첫 번째 문장으로 반복되지 않는지 확인합니다.
8. 공유 클립보드가 계속 ON인지 확인하고, 로컬 앱에서 복사한 다른 글을
   원격 입력칸에 일반 붙여넣기로 넣은 뒤 Handy 음성 입력을 다시 확인합니다.

해당 모드의 붙여넣기 명령을 사용할 수 없으면 실패를 알리고 기록에 남깁니다.
기본 Paste가 시간 초과된 경우 이미 입력되었을 수 있으므로 원격 문서를
먼저 확인하고 재시도하세요. Handy는 중복 입력을 막기 위해 자동 재시도하지 않습니다.
네트워크 지연이 크면 Handy 설정에서 붙여넣기 지연을 늘려 주세요.

업데이트와 공유
---------------
화면 공유 수정이 원본 앱으로 덮어써지는 것을 막기 위해 이 배포본에서는
앱 내 업데이트 확인/설치를 껐습니다. 새 수정본은 DMG로 직접 교체합니다.
앱 이름과 설정 저장 위치는 원본 Handy와 같으므로 별도 앱으로 공존하지 않습니다.

SNS로는 DMG 파일 하나를 전달하면 됩니다. DMG 첨부를 지원하지 않는 서비스는
해당 파일을 파일 공유 서비스에 올린 뒤 다운로드 링크를 전달하세요.
공유 시 '비공식 화면 공유 수정본 / 파일명의 CPU 아키텍처 / 최초 실행 보안 승인 필요'를
함께 알려 주세요. 이 안내문과 라이선스는 DMG 안에도 포함되어 있습니다.
